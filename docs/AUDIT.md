## 后台策略

已检查以下链路：

- 网易云 Cookie 只用于网易云域名请求，不写入扩展存储。
- 飞书写入前重新读取当前账号，并与绑定的稳定账号 ID 比较。
- 只接受来自扩展自身 `popup.html` 的后台消息。
- 临时请求头规则在 `finally` 中清理。
- 后台使用单一活动任务锁，避免手动同步和闹钟并发写入。
- 改绑其他飞书账号时自动关闭每日同步并清除旧闹钟。
- 每日任务按香港时间安排；休眠延迟和浏览器晚启动时支持当天补跑。
- 同一天已经产生运行结果后不持续重试，避免数据源异常时反复写入。

## 本轮修复

1. 移除无法可靠读取原值的“恢复原签名”，避免把签名误清空。
2. 增加安全改绑与解除绑定流程。
3. 修复网易云登录打开新标签页后，弹窗关闭导致确认流程丢失的问题。
4. 把账号与最近播放合并为一次自动读取。
5. 迁移旧闹钟名称，并补充扩展升级后的当天补跑。
6. 统一清理歌曲文本中的异常空白。

## 保留风险

- 飞书签名写入依赖网页版内部接口，平台改版可能导致功能暂时失效。
- 扩展无法可靠读取飞书当前签名；用户手动修改后，新的歌曲同步仍可能覆盖它。
- 定时执行依赖 Chrome 运行和两个网站的登录会话有效。
- Cookie 权限与内部接口可能增加 Chrome Web Store 审核难度；这不影响 GitHub 源码发布，但商店提交需要单独评估届时政策。
